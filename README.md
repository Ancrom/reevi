# Reevi — Портфолио Natali Samutina

Персональный сайт-портфолио художницы Natali Samutina. Проект представляет собой современное веб-приложение для демонстрации художественных работ (концепт-арт, иллюстрации) с интеграцией системы управления контентом (CMS).

## 🚀 Стек технологий

### Frontend
- **React 19**
- **Vite**
- **TypeScript**
- **Sass (SCSS)**
- **React Router 7**
- **Sanity Client**
- **grid-rows-masonry**

### Backend (CMS)
- **Sanity Studio v3** — headless CMS для управления контентом (загрузка работ, описание, категории).

## 📁 Структура проекта

```text
├── frontend/          # Исходный код фронтенд-приложения (React + Vite)
├── sanity/            # Конфигурация и схемы Sanity Studio (CMS)
├── package.json       # Общие скрипты управления проектом
└── README.md          # Документация проекта
```

## 🛠️ Установка и запуск

Для работы проекта необходим [Node.js](https://nodejs.org/).

### 1. Клонирование репозитория
```bash
git clone <url-репозитория>
cd reevi
```

### 2. Установка зависимостей
Необходимо установить зависимости в корне, а также в папках `frontend` и `sanity`:
```bash
# В корне проекта
npm install

# В папке фронтенда
cd frontend && npm install

# В папке CMS
cd ../sanity && npm install
```

### 3. Запуск в режиме разработки

Для одновременного запуска фронтенда и студии Sanity (в разных терминалах):

**Frontend:**
```bash
cd frontend
npm run dev
```
Приложение будет доступно по адресу `http://localhost:5173`.

**Sanity Studio:**
```bash
cd sanity
npm run dev
```
Студия будет доступна по адресу `http://localhost:3333`.

## 🚢 Сборка и Деплой

Проект настроен для деплоя на **GitHub Pages**.

В корневом `package.json` настроены скрипты для автоматизации процесса:

- `npm run build:frontend` — сборка фронтенда.
- `npm run build:sanity` — сборка Sanity Studio в подпапку `dist/admin` фронтенда.
- `npm run deploy` — полная сборка проекта и публикация ветки `gh-pages`.

Для выполнения деплоя просто запустите:
```bash
npm run deploy
```

После успешного выполнения сайт будет доступен по адресу, указанному в настройках GitHub Pages вашего репозитория.

## 🎨 Управление контентом

Все работы, категории и текстовая информация управляются через Sanity Studio. После входа в студию (локально или по развернутому адресу) вы можете добавлять новые работы, изменять их порядок и описания.
